# pairwise-timeline-ripple

我们的时间线编辑器现在只支持普通删除，产品要波纹编辑：删除片段后同轨道后续片段整体前移，转场锚点跟着相邻片段走，关键帧按片段新起点重算，锁定轨道不能被波纹影响，多选删除要按反向顺序累计位移。timeline/ripple.py 是核心，tests/test_ripple.py 15个红。要修的是：删除时长按帧对齐后精确累计；只影响目标轨道且跳过锁定片段；转场锚点同时返回左片段 end 和右片段 start；关键帧相对时间随片段平移；多选删除先删后面的再删前面的；输出按轨道和起点排序；目标不存在时明确报错。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
